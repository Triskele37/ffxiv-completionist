Marking Completion
When you navigate down to a group that has tasks that can be marked for completion there will be a table
On the left of that table is the completion column
  • Left Click: Toggle the task from "not done" to "done" or vise versa, also removes the "excluded" marking
  • Right Click: Mark the task as "excluded"
Number Based Completion
Some groups may have completion based on a range of numbers
In these tables the completion column will instead contain an input field to manually enter the value
These fields validate data entered into them, so data entered may be changed to fit within a range
These fields only commit the data entered after clicking away from them
Quick-Mark Completion
Above the table is an overlay menu that has several options for altering completion state of many tasks at once
Custom Tasks
An area where tasks can be entered that the app does not have in it along with notes on each one
Custom tasks can be edited by selecting them
Custom tasks can be reordered through the action menu
Custom tasks also have the ability to merge into the app, allowing for easier updates after patches
Notes about merging:
  • Merge searches are case-insensitive and ignores anything that isn't a letter or number
  • Merge searches look for the whole name of the task, partials will not be displayed
  • Upon clicking one of the matches for merge, that Custom Task will be removed along with its notes
  • All tasks with a single match can be auto-merged without needing to confirm each one
Calculations
Completion for any group is calculated as the percentage of total items completed of all child items of that group, excluding any items marked as "excluded"
Items are not weighted so completing an ultimate nets the same progress as crafting an Oak Lumber
Final Notes
Hovering over the progress bar for any group gives you a tooltip detailing that group's completion numbers
