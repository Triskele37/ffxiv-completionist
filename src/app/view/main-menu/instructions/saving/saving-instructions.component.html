Overview
The app creates a save with a default name in a default location
The currently active save can be viewed in the settings page
New Character
In the settings page additional save files can be created
When clicked, the file name and location can be customized
Load Character
In the settings page an existing save file from the app can be loaded
Use this action if the save file has been moved manually
Files
The app relies on 2+ files to handle save data
  • "config.json": Holds configuration data for the app itself
  • "completion.json": Holds save data for characters, can be renamed to anything
NOTE: Modifying these files manually may lead to unexpected issues, especially with the app open
"Backup"
It is highly recommended to backup the completion save either manually or automatically
This is especially important when updating the app to a new version

Example of manual backup:
  1. Locate the completion save file
  2. Copy it to a safe location
  3. Don't load this backup with the app
Example of automatic backup:
  1. Ensure the app is closed
  2. Move the completion save file to a folder that is automatically cloud saved
  3. Use the "Load Character" action to load from the new location
Final Notes
Completion is saved as soon as items are marked
Completion is migrated between versions of the app
  • Sometimes Patch Notes will indicate items that need to be manually reviewed
