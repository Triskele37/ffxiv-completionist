Sorting
Columns can be sorted by clicking the column title
The icons in the column headers indicate the currently active sort
All Task View
When "All Task View" is enabled, all tasks within that view are grouped into a collapsed header
All actions work as expected despite the tasks not being visible
Filter Columns
At the top of each column is a text input to filter tasks in that table
This input may have a dropdown if the column has few unique values
This filter is case-insensitive and matches anywhere within the text for that column
Filtering Completion
At the top of non-numeric completion columns are 3 icons that indicate "completed", "not completed", and "excluded"
These can be enabled/disabled separately and their state is saved between tables and reloads
Items in the table that match any enabled icon will be displayed
Select Items
Clicking on any row will "select" it and turn it a different color
An overlay menu above the table contains actions regarding selection
In Crafting Log groups this menu contains an option to export all selected recipes to external sites
Row Actions
The last column in every row has a "Row Action" menu
Two of these actions attempt to export the task to external sites
NOTE: Not all tasks can export properly, please report those that would make sense if they did
Final Notes
In order to accomodate quick rendering of particularly large groups, all tables implement "virtual scrolling"
As tables are scrolled, their header may jitter, this is a product of that feature
