Search Columns

At the top of each column is a combo input used to search/filter that column

This input allows free-text, and in certain columns a dropdown of unique values

This search is case-insensitive and matches anywhere within the text for that column


Filtering Completion

At the top of the completion column are 3 icons that indicate "completed", "not completed", and "excluded"

These can be enabled/disabled separately and their state is saved between tables and reloads

Items in the table that match any enabled icon will be displayed


Select Items

Clicking on any row will "select" it and turn it a different color

A dropdown above the table allows for a few options with selecting as well

Within the Crafting Log groups, there are options to open all selected recipes in other sites


Links

To the right of most items is a link to "Gamer Escape" and "Garland Tools"

These links attempt to generate their own url based on the task they're for

If you see a link that doesn't navigate to the correct content, please report it so it can be fixed
